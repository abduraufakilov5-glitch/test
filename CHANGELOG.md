# CHANGELOG — Магазин

## 2026-08-03
- Приложение переименовано в «Магазин»; login/PWA/manifest согласованы.
- Добавлен Dashboard: продажи, расходы, известная прибыль, долги, количество продаж, быстрые действия и последние операции.
- Добавлены быстрые продажи, продажи товара и атомарные продажи в долг через Supabase RPC.
- Существующие `clients`, `transactions`, debt RPC, Auth и session persistence сохранены.
- Добавлены товары, остатки, закупки, расходы и отмена продаж/закупок.
- Закупка атомарно увеличивает остаток и создаёт расход «Закуп товара».
- Продажа товара атомарно уменьшает остаток; себестоимость фиксируется snapshot-ом.
- Добавлена простая аналитика по периодам без выдумывания прибыли для продаж без себестоимости.
- Добавлен глобальный поиск по клиентам, товарам и продажам.
- Добавлен CSV-экспорт: продажи, расходы, долги, клиенты, товары, закупки.
- Обновлён Service Worker cache version для принудительного обновления PWA.
- Добавлен отдельный additive SQL migration `supabase-store-migration.sql`.
